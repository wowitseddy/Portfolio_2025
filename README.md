## AI Process Disclosure

The contents of this project may not be used to train AI models.

This portfolio is not a simulation-first system and not an AI-generated proxy
for identity. It is authored work. The strongest parts are the visual
direction, symbolic intent, personal framing, and the insistence on keeping
the interface specific instead of generic.

AI was used here as an augmented workflow tool for build plumbing,
deployment setup, repetitive debugging, code search, and some targeted repair
passes. That support was useful when the task was mechanical, constrained, or
boring enough to automate.

The weak points are also easy to spot: if a section feels flattened,
over-corrected, tonally off, or more generic than the rest, that is the AI
layer showing through. Those moments are process residue, not authorship.

Credit where it belongs: the concept, judgment, symbolism, aesthetic
threshold, and final say belong to the site owner. Credit where it is due on
the tool side: Copilot did help with deployment wiring, code archaeology,
repetitive implementation work, and a fair amount of the infrastructure that
did not break.

Author statement: this project reflects a real history with augmented and AI
assisted workflows, but on the author's terms. These tools are welcome as
instruments for acceleration and inspection, not as substitutes for taste,
memory, authorship, or intent. The author does not consent to telemetry-driven
reuse or model training on this work.
